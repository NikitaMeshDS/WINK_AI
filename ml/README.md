# ML Service для обработки сценариев

Сервис для автоматического извлечения структурированных данных из сценариев фильмов с использованием модели Qwen2.5-14B-Instruct.

## Системные требования

### Технические требования
- **GPU**: NVIDIA A40 с 48GB VRAM
- **RAM**: 64GB системной памяти
- **Диск**: 100GB свободного места
- **CUDA**: версия 12.1 или выше
- **Python**: 3.10 или выше

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/NikitaMeshDS/WINK_AI/tree/ml-server.git
```

### 2. Установка зависимостей

```bash
cd ml
pip install -r requirements.txt
```


### 3. Запуск сервиса

```bash
python main.py
```

Сервис запустится на `http://0.0.0.0:8000`

## API Endpoints

- `POST /analyze` - Загрузка и обработка .docx файла со сценарием
- `GET /result` - Получение последних результатов обработки
- `GET /health` - Проверка статуса сервиса



- **Модель**: Qwen/Qwen2.5-14B-Instruct
- **Размер батча**: 8 сцен (настраивается в `main.py`)
- **Flash Attention 2**: Включен для оптимизации памяти и скорости
- **Максимальная длина ответа**: 1500 токенов

## Troubleshooting

### Ошибка "Out of Memory"
- Уменьшите `BATCH_SIZE` в `main.py`
- Используйте GPU с большим объемом VRAM

### Ошибка при установке flash-attn
- Убедитесь, что установлены CUDA toolkit и компилятор C++
- На Windows может потребоваться Visual Studio Build Tools

### Модель не загружается
- Проверьте подключение к интернету (первая загрузка модели)
- Убедитесь, что достаточно места на диске
